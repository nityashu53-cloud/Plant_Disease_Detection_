Plant Disease Detection Using CNN

Project Overview

This project uses a Convolutional Neural Network (CNN) to identify plant leaf diseases from images.

Plant Categories:

The dataset contains 15 categories from-

- Tomato
- Potato
- Bell Pepper

Technologies Used:

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

Methodology:

1. Dataset Collection
2. Data Preprocessing
3. Train, Validation and Test Split
4. CNN Model Creation
5. Model Training
6. Model Evaluation
7. Image Prediction

Dataset:

PlantVillage Dataset: https://www.kaggle.com/datasets/arjuntejaswi/plant-village

Model Evaluation:

Actual test accuracy, precision, recall and F1-score are available in the evaluation results.

Future Scope:

More plant varieties and disease categories can be added to improve project coverage.
